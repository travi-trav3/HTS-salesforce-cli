# Project memory — Club Pilot Design System

## Copywriting / typographic rules

- **Capitalize open-class (content) words in all graphics and design material.** In any headline, title, eyebrow, button, label, card title, or other display copy, use title case: capitalize nouns, verbs, adjectives, adverbs, and pronouns. Leave closed-class (function) words lowercase unless they are the first or last word — articles (a, an, the), coordinating conjunctions (and, but, or, nor, for, so, yet), and short prepositions (in, on, of, to, at, by, up, etc.).
  - Example: "Three Ways to Reach Every Member" (not "Three ways to reach every member").
  - Applies to display/graphic copy. Running body paragraphs and conversational/chat-bubble copy stay in normal sentence case.
- **No orphans.** Never let a single word fall alone on its own line in a headline, title, or any display copy. Size the type or set the line breaks so each line carries more than one word. Only exception: a deliberate single word on its own line used for emphasis.

## Logo / wordmark sizing

- **The Club Pilot wordmark must never be timid.** Enforce a minimum height: **≥88px on 1080px-wide social formats** (IG/ad squares & portraits) and **≥104px on 1200px-wide LinkedIn formats**. Scale up from there as the composition allows — never go below these minimums. The wordmark should read as a confident, prominent brand presence, not a small corner tag.
