One-line: Club Pilot's fully pill-shaped action button — use `primary` (orange gradient) for the main CTA, `secondary` (azure) for the second action, `brand` (green) for in-product/confirm.

```jsx
<Button variant="primary" size="lg" href="#demo">Book a Demo</Button>
<Button variant="secondary">Log In</Button>
<Button variant="outline" size="sm">Learn More</Button>
```

- Labels are auto-uppercased and tracked. One dominant action per composition — don't put orange and azure side by side as equals.
- Variants: `primary | secondary | brand | outline`. Sizes: `sm | md | lg`.
